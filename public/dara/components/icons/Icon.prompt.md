Thin-line single-color icon (Lucide paths); use sparingly for wayfinding — never decoration.

```jsx
<Icon name="map-pin" size={20} />
<span style={{ color: "var(--dara-sage-deep)" }}><Icon name="check" size={16} /></span>
```

Color comes from `currentColor`. Available: check, chevron-down, arrow-right, x, map-pin, shield-check, clock, plus. Intentional addition — the brand has no bespoke icon set; extend from Lucide (1.75 stroke) only when needed.
